    2-2 대체주소 사전 선택

    지난번 작업에서 내려받은 사전 엑셀을 올리면, 그때 확정한 지명형 주소는 API 호출 없이 바로 채워집니다. 처음이라면 그냥 넘어가세요.

    2-1 좌표계 확인 중요

    카카오는 WGS84 경위도를 반환하지만 기존 시트의 X/Y는 투영좌표계(미터)입니다. 잘못 고르면 신규 등록분만 수백 m 어긋나므로, 기존 좌표가 있는 행으로 자동 판정하는 것을 권장합니다.
